02 / WHAT IT CHECKS

History is
evidence.

Established scanners do the secret detection. Did I Leak? adds the context that makes their output useful before a public push.

01NOW

Current tree

Tracked, staged, unstaged, untracked, and ignored files such as `.env` where they actually exist.

02THEN

Reachable history

All reachable commits, branches, tags, deleted historical files, and blobs that current code forgot.

03SAFE

Redacted output

No full credentials in the terminal, JSON, examples, or handoff. You see the risk, not the secret.

The rule

“Deleted” is not the same as “never exposed.”

If a real credential was ever committed or shared: revoke it first, verify its replacement is absent, then decide whether history cleanup is worth the consequences.
